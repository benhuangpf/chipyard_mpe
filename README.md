# MPE on Chipyard
## Introduction
This MPE(Memory Protection Engine) is originated created by Omori Yu (https://github.com/uyiromo/OpenMPE/tree/master). In the paper ’Open-Source Hardware Memory Protection Engine Integrated With NVMM Simulator’[1], Memory Protection Engine(MPE) is implemented on the RISC-V SoC on an FPGA. The original development was based on the Freedom platform. However, Freedom is no longer actively maintained or supported for the VC707 FPGA board, which poses significant challenges for integrating new modules and continuing development. As a result, the project is transitioning to a new platform and FPGA target.
